# BRISQUE model data

These are the pretrained LIVE-R2 BRISQUE model and feature-range files shipped
with the OpenCV quality-module samples:

- `brisque_model_live.yml`
- `brisque_range_live.yml`

They are pinned to the OpenCV Contrib 5.0.0 release:

- https://github.com/opencv/opencv_contrib/blob/5.0.0/modules/quality/samples/brisque_model_live.yml
- https://github.com/opencv/opencv_contrib/blob/5.0.0/modules/quality/samples/brisque_range_live.yml
